## 🎵 About Couple’s Hear

**Couple’s Hear** is a synchronized audio player designed to bring couples and close friends together through music, no matter the physical distance. 

Create a private 6-character room, share the link or room code with your partner, and listen to music simultaneously with sub-second drift calibration.

### ✨ Key Features

- **⚡ Real-Time Synchronized Playback**: Play, pause, seek, and track transitions sync instantly across all devices.
- **🕒 Sub-Second Drift Correction**: Automatic network latency compensation and periodic sync ticks ensure both listeners hear the same second together.
- **🔒 Instant Private Rooms**: Generate a unique 6-character room code with 1-click invite link copying.
- **🎶 Built-in Playlists & Custom Uploads**: Enjoy preloaded romantic songs or upload your own MP3/WAV/AAC tracks.
- **📱 Installable Progressive Web App (PWA)**: Add to home screen on iOS Safari, Android Chrome, and Desktop with offline caching.
- **💬 Real-Time Reaction Floating Hearts**: Send live interactive heart animations and reactions while listening together.

## 🚀 Live Demo & Deployment

Deployable instantly to **GitHub Pages** using the included GitHub Actions workflow (`.github/workflows/deploy.yml`).

### Setting up GitHub Pages:
1. In your GitHub repository, navigate to **Settings** &rarr; **Pages**.
2. Under **Build and deployment** &rarr; **Source**, select **GitHub Actions**.
3. Push to `main` or trigger the workflow manually from the **Actions** tab.
